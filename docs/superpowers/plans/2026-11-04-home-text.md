# Editable Homepage Text Implementation Plan

**Goal:** Let admins update homepage copy directly in the rendered layout while preserving both photo editors.
**Architecture:** Typed copy fields/defaults; versioned Prisma record; public GET and authorized PUT; inline textarea consumers and a fixed save/cancel toolbar.
**Tech Stack:** Next.js 16, React 19, Prisma, PostgreSQL, Zod, Vitest.
**Spec:** docs/superpowers/specs/2026-11-04-home-text-design.md

## Constraints
Keep photo editors, navigation targets and deferred loading. Plain text only; admin permission never shared-cacheable. Protect drafts on failures/concurrent updates. Merge each research title and remove the member description.
